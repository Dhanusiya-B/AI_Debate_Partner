AI Debate Partner:
An interactive AI-powered web application that challenges users in real-time debates, helping them improve critical thinking, communication, and argumentation skills.

Overview:
AI Debate Partner allows users to:
Select or create a debate topic
Choose a stance (For / Against)
Engage with an AI opponent that argues the opposite side intelligently
The system simulates real-world debates, pushing users to think deeper and respond effectively.

Features:
Topic Selection:
Predefined categories (Technology, Society, Science, Politics)
Custom topic input
AI Opponent:
Uses Claude AI to generate counter-arguments
Responds dynamically based on user input
Stance Selection:
Choose "For" or "Against"
AI automatically takes the opposite stance
Real-time Debate:
Interactive conversation flow
Continuous argument exchange
Modern UI:
Clean, dark-themed interface
User-friendly experience

Tech Stack:
Frontend:
React.js
HTML5
CSS3
Backend:
Node.js
Express.js
API Integration:
Groq AI API
